# Back_end1 — Sistema de Gestión de Transporte

Proyecto desarrollado en Django para la gestión de vehículos, choferes y rutas.

## 🚀 Requisitos previos

- Python 3.10+
- pip
- Git

## 📦 Instalación

1. Clonar el repositorio
```bash
git clone https://github.com/nelsito23pro/Back_end1.git
cd Back_end1
```

2. Crear el entorno virtual
```bash
python3 -m venv ambiente_1
```

3. Activar el entorno virtual
```bash
source ambiente_1/bin/activate
```

4. Instalar las dependencias
```bash
pip install -r requirements.txt
```

5. Aplicar las migraciones
```bash
python3 manage.py migrate
```

6. Levantar el servidor de desarrollo
```bash
python3 manage.py runserver
```

7. Abrir en el navegador
